# Licensed demonstration catalog

`catalog.sources.json` defines the real open-film selection and its source,
license and attribution. `scripts/Sync-Catalog.ps1` resolves artwork from each
film's authoritative Blender Studio page and writes `catalog.json`.

The app must display the attribution and license/source links, not imply a
partnership or privately negotiated distribution agreement. Rental/purchase
prices are MSFlix demonstration commercial offers, not Blender's official prices.
The catalog is intentionally independent/open cinema so image reuse is legally
traceable instead of silently copying a commercial streaming service's posters.
